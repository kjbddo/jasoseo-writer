# 페르소나 문서 템플릿 (1단계)

지원자 프로필을 아래 구조로 만든다. ⚠️ 표시는 추정으로 채운 부분 — 사용자가 교체해야 한다.

```markdown
# 자기소개서 페르소나

> 모든 자소서 작성의 기준 프로필. 문항이 달라져도 여기서 소재를 꺼내 쓰며, 사실관계는 여기에 맞춘다.
> ⚠️ 표시는 추정으로 채운 부분이라 사실 확인·수정이 필요.

## 1. 기본 프로필
- 지원 포지션 / 경력 구분(신입·경력N년·전환)
- 학력·전공, 졸업(예정) 시점
- 직무 교육·부트캠프(기간·시간)
- 자격증(보유/준비, 취득 시점)
- 이름 / 학점 / 어학 ⚠️

## 2. 한 줄 정체성 (Positioning)
- "○○을 다지고 ○○을 해 본 ○○ 지원자" — 차별점 한 문장

## 3. 핵심 강점 키워드 (3~4개, 자소서에서 반복 강조)

## 4. 기술 스택 (실제 다뤄본 범위)

## 5. 대표 프로젝트/경험 (스토리 소재)
- 각 경험: 개요 · 본인 역할 · 강조축 · ⚠️확인 필요 항목

## 6. 스토리라인 (성장 서사)
- 왜 이 분야인가 / 왜 이 직무인가 / 왜 이 회사인가

## 7. 직무별 강조 포인트

## 8. 확인·보완 필요 목록 (⚠️ 요약)
```

## 진행 팁
- 이력서·포트폴리오·GitHub·커리큘럼을 먼저 읽어 자동으로 채운다.
- 부족한 부분만 `AskUserQuestion`으로 묻는다: 지원 직무 / 경력 구분 / 졸업 시점 / 자격증 /
  대표 경험 / 지원 회사 유무.
- 이름 등은 포트폴리오·저장소명에서 유추 가능하면 유추하되, 확정은 사용자에게 받는다.
