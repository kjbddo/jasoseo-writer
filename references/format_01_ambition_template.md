# 입사 후 포부 (전용 템플릿)

'입사 후 포부/비전' 문항 전용. 아래 **두 가지 메인 골격 중 문항 성격·취향에 맞는 것을 골라** 쓴다.
(사용자가 별도 양식을 첨부하면 그 양식을 최우선으로 따른다.) 어느 골격을 쓸지 **사용자에게 확인**한다.

---

## 골격 A — 첫째·둘째·셋째·마무리 (미래형 · 양식형)

`format_02`('직무 수행을 위한 노력', 과거형)의 **미래형 쌍**이다 — 과거에 '했다'가 아니라 '하겠다'로 쓴다.

```
저는 [지원 직무] 직무에 있어서 [○○ 역량]을 향상하기 위해 다음과 같이 노력하겠습니다.

첫째, 직무에서 필요한 [역량A]을 위하여 [노력1], [노력2], [노력3]의 노력을 하겠습니다.
특히, [핵심 노력/경험]을 통해 [지식/기술 A], [B], [C] 역량을 습득하겠습니다.
예를 들어 [사례 a], [b], [c] 등 직무에서 요구하는 [역량A]을 위한 [세부] 역량을
습득하는 데 큰 도움이 될 것입니다.

둘째, 직무에서 필요한 [역량B]을 위하여 … (첫째와 동일 구조)
셋째, 직무에서 필요한 [역량C]을 위하여 … (첫째와 동일 구조)

마무리: [입사 후 기여·성장 다짐 한 줄]
```
- **언제**: 이 양식을 첨부했을 때, 또는 문항이 '노력·역량 향상 방향'을 폭넓게 물을 때. 직무수행노력과
  대칭이라 세트로 제출하기 좋다.

---

## 골격 B — 시점별 로드맵 (3·6개월·1·3년 · 로드맵형)

```
[3개월]  목표: … / 실행방안: … / 기대결과: …
[6개월]  목표: … / 실행방안: … / 기대결과: …
[1년]    목표: … / 실행방안: … / 기대결과: …
[3년]    목표: … / 실행방안: … / 기대결과: …
```
- 초반(3·6개월)=적응·기준 습득, 중반(1년)=독립 수행·자동화 사례 1건, 장기(3년)=개선 제안·리드.
- **언제**: 문항이 '시기별 계획/입사 후 N년 로드맵'을 물을 때, 또는 실행력·구체성을 시간축으로 강하게
  보여주고 싶을 때. 포트폴리오의 '성장 로드맵' 슬라이드에도 이 골격을 쓴다.

> 본문 구조(로드맵형): ① 한 줄 포부 선언(두괄식) → ② 강점 개발 축 + 약점 보완 축(믹스) →
> ③ 시점별 로드맵(목표·실행방안·기대결과) → ④ 회사·직무 연결로 마무리.

---

## 반드시 지킬 것 (두 골격 공통)
1. **강점 개발 + 약점 보완을 '믹스'.** 잘하는 것을 더 키우는 축 + 부족한 것을 메우는 축을 함께 담는다.
   (골격 A는 첫째·둘째·셋째에, 골격 B는 시점/항목에 분배)
2. **구체적 실행방안을 '반드시' 포함.** "열심히"가 아니라 *무엇을 어떻게*(예: Terraform으로 반복 인프라
   코드화, 사내 스터디로 K8s 학습, 오픈소스 기여 등) 실제 행동으로.
3. **3가지 버전 제안 → 선택.** 강조 축이 다른 3버전을 제안하고 사용자가 고르게 한다
   (버전 A 전문성 심화형 / 버전 B 확장·보완형 / 버전 C 회사 기여형).
4. **미래형 어미 유지.** "~하겠습니다 / 습득하겠습니다 / 큰 도움이 될 것입니다".

## 참고
- 회사 방향(주요 서비스·사업, `07_company_fit.md`)과 연결하면 "이 회사에서의" 포부가 된다.
- 로드맵·실행방안의 수치·사례는 '계획'이므로 과장 금지. 현재 역량과 자연스럽게 이어지게 쓴다.

## 사용자 확인 지점
- **골격 A(양식형) vs 골격 B(로드맵형)** 중 선택.
- 강조할 3버전(전문성 심화 / 확장·보완 / 회사 기여) 중 방향.
