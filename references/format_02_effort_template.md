# '직무 수행을 위한 노력' 양식 (6단계)

## 골격

```
[직무] 직무 준비 경험

저는 [직무] 직무를 수행하기 위해 다음과 같은 노력을 했습니다.

첫째, 직무에서 필요한 [역량A]을 위하여 [경험1], [경험2], [경험3]을 경험했습니다.
특히 [경험1]을 통해 [지식/기술 A·B·C] 역량을 습득할 수 있었습니다.
예를 들어 [구체 사례 a·b·c] 등 직무에서 요구하는 [역량A]을 습득하는 데 큰 도움이 되었습니다.

둘째, 직무에서 필요한 [역량B]을 위하여 [경험4], [경험5], [경험6]을 경험했습니다.
특히 …

셋째, 직무에서 필요한 [역량C]을 위하여 [경험7], [경험8], [경험9]을 경험했습니다.
특히 …

마무리: 세 축을 갖추었기에 [지원 회사/팀]에서 [기여]하겠습니다.
```

## 작성 규칙
- **세 축(첫째·둘째·셋째)** 은 지원 공고가 요구하는 핵심 역량 영역으로 잡는다.
- 각 축마다 대표 경험을 앞세우고, "특히 ○○을 통해 ○○ 역량"으로 구체화한 뒤,
  "예를 들어 ○○" 로 근거를 든다.
- 공고의 필수·우대 키워드를 본문에 자연스럽게 녹인다.
- 마무리는 회사·팀 특성(MSP/SI/서비스사/AI팀 등)에 맞춰 조정한다.

## 공고 비교 분석표 (본문 앞에 배치)

| 공고 요구 (필수/우대) | 보유 경험·근거 | 적합도(★) |
|---|---|---|
| 요건1 (필수) | 대응 경험 | ★★★ |
| … | … | … |
| 미충족 요건 (예: 경력 4년) | 신입 — 미달 | ✕ |

- 하드 게이트(경력 연차·어학 등) 미충족은 솔직히 표기하고, 하단에 **지원 전략**을 제시한다:
  도전 지원 / 신입·주니어 트랙 확인 / 경력 인정 요소 확인 / 단기 보완 포인트.
