# 포트폴리오 확장 (핸드오프)

자소서 재료(페르소나·역량 정리표·경험 개요)는 그대로 **포트폴리오**의 콘텐츠가 된다. 자소서가
정리되면 포트폴리오로 확장할 수 있다. 제작은 형식에 맞는 **다른 스킬로 넘긴다(핸드오프)**.

## 1. 콘텐츠 정리 (공통)
경험을 포트폴리오 구조로 배치한다. 두 패턴 중 선택:
- **기승전결 패턴**: 기(프로필·강점) → 승(성장·배운것) → 전(성과·핵심역량) → 결(비전·로드맵)
- **역량 중점 패턴**: 강점/역량 축으로 경험을 묶어 제시
→ 엑셀 정리표가 필요하면 **xlsx 스킬**, 문서면 마크다운으로.

## 2. 톤앤매너 확인 (⚠️ 필수 게이트 · 제작 전 반드시)
**포트폴리오를 생성하기 전에 톤앤매너를 반드시 사용자에게 물어 확정한다. 이 확인 없이는 어떤 형식도
제작에 착수하지 않는다.** `AskUserQuestion`(또는 질문 목록)으로 아래를 묻는다:
- **기준 레퍼런스**: 지원 기업 홈페이지 / 특정 브랜드·사이트 / 사용자 지정(색·무드) / 제안 받기
- **색상 방향**: 예) 딥네이비 엔터프라이즈, 밝은 미니멀, 브랜드 4색 등
- **무드**: 전문적·테크·미니멀·친근 등
- **폰트/기타 선호**(있으면)

기준을 **지원 기업 홈페이지**로 하면, 아래를 **웹 검색/공식 사이트로 최신 확인**해 추출하고
**그 결과를 사용자에게 보여주고 확인받은 뒤** 제작에 들어간다:
- **색상**(배경·강조·텍스트 hex), **폰트/타이포**, **무드 키워드**, **주요 서비스·사업 라인업**,
  **시각 요소**(다이어그램·노드·데이터 흐름 등), **레이아웃 원칙**(여백·카드·한 장=하나 메시지).
- 브랜드를 그대로 복제하지 말고 포트폴리오용으로 재해석. 색상바/엣지 스트라이프 남용 금지.

## 3. 출력 형식 선택 (사용자 확인 지점) — **PPT / 웹페이지 / 노션 페이지 중 하나**
반드시 사용자에게 어느 형식으로 만들지 확인한 뒤, 해당 경로로만 진행한다.

---

### A. PPT (.pptx) — pptx 스킬로 핸드오프  ※ 아래 상세는 PPT를 선택했을 때만 적용

**A-1. 디자인 프롬프트 3종** (목적별로 나눠 제시)
- **① 전체 디자인용**: 컬러 시스템·타이포·시각요소·디자인 원칙 전반.
- **② 표지/메인 콘셉트용**: 핵심 메시지 한 문장 + 하단 키워드 배치, 배경 콘셉트.
- **③ 전체 슬라이드 구성용**: 10~13장 흐름(표지→직무목표→강점→역량맵→대표 프로젝트→문제→해결→결과→성장→적합성→로드맵→글로벌→마무리)을 톤앤매너로.

**A-2. 통합 제작 프롬프트 (코덱스·외부 도구용, 8섹션 골격)**
① 제작 목적(핵심 콘셉트 한 줄 + 보여줄 역량) · ② 지원자 설정(보유 역량 / 보완 중 역량 구분) ·
③ 전체 디자인 콘셉트(컬러·시각요소·디자인 원칙) · ④ 추천 슬라이드 구성(장별 제목·메시지·콘텐츠) ·
⑤ 문장 작성 기준(A-4) · ⑥ 제작 방식(pptxgenjs 권장·편집 가능·이미지 대체) ·
⑦ 산출물(A-5) · ⑧ 최종 검수(A-6). **끝에 '사실 잠금 문구'(하단)를 반드시 붙인다.**

**A-3. 첫 실행 후 수정용 프롬프트** (1차 생성물 리뷰용)
학생 과제풍 → B2B 제안서 스타일로 / 긴 문장 30%+ 축약 / 컬러 시스템 통일 / 프로젝트 페이지는
텍스트보다 아키텍처·문제해결 흐름 중심 / 핵심 강점이 반복 연결되도록 / 로드맵은 실행방안까지 구체화 /
슬라이드 PNG로 잘림·겹침·작은 글자 확인 후 재저장.

**A-4. PPT 문장 작성 기준**
한 문장 25자 내외 · 카드당 2~3문장 · 제목은 메시지가 드러나는 문장형 · "열심히/최선을" 같은 추상표현
최소화 · 행동·결과 중심 · 핵심어는 강조색 · 기술명 표기 일관.

**A-5. 산출물 명세**
최종 `.pptx` + **슬라이드별 PNG 미리보기** + **슬라이드 구성안 `.md`**(장별 제목·메시지·콘텐츠·디자인 의도)
+ 사용한 컬러·폰트·레이아웃(디자인 시스템) 정리.

**A-6. 검수** — pptx 스킬의 시각 QA(넘침·겹침·작은 글자·정렬)로 PNG 렌더 확인 + `06_evaluation.md`
최종 검수 체크리스트. 11~13장, 한 장=하나 메시지, 카드 최대 4개, 넉넉한 여백 유지.

---

### B. 웹페이지 (HTML) — web-artifacts-builder / 자기완결 HTML로 핸드오프
- **단일 파일 자기완결 HTML**(인라인 CSS/JS, 이미지는 data URL) 또는 복잡하면 **web-artifacts-builder**
  (React·Tailwind)로 제작.
- 톤앤매너(2번) 반영, 섹션 = 기승전결/역량중점, **반응형**, 상단/사이드 스크롤 내비게이션.
- 다시 볼 산출물이면 **아티팩트로 저장**(create_artifact)해 지속.
- 산출물: `index.html`(자기완결).

### C. 노션 페이지 — Notion MCP로 핸드오프
- **Notion MCP**(예: notion-create-pages)로 페이지 생성, 또는 붙여넣기용 **마크다운 초안** 제공.
- 섹션 구조(기승전결/역량중점) + 콜아웃·토글·구분선으로 위계, 프로젝트별 서브페이지/이미지 첨부.
- 공유 가능한 페이지. 산출물: Notion 페이지 URL(또는 마크다운 파일).

---

## 사실 잠금 문구 (모든 형식 공통 · AI 임의 변경·날조 방지)
제작을 다른 도구(코덱스·커서 등)에 맡길 때, 프롬프트 말미에 반드시 넣는다:
> "핵심 콘텐츠와 지원자 페르소나(전공·직무전환·대표 프로젝트·강점·성장 방향)를 임의로 바꾸지 말 것.
> 성과 수치·수상·자격증·기업 프로젝트 경험을 임의로 생성하지 말 것. 내용이 부족하면 분량을 줄이거나
> 정성적 표현으로 작성할 것."

## 범위 메모
이 스킬의 본체는 '자소서 글쓰기'다. 포트폴리오는 확장 옵션이며, 실제 파일 제작은 형식에 따라
**pptx(PPT) / web-artifacts-builder·HTML(웹) / Notion MCP(노션) / xlsx(정리표) / canvas-design(이미지)**
스킬이 담당한다. 여기서는 **콘텐츠 매핑·톤앤매너 추출·형식별 핸드오프 프롬프트**까지를 책임진다.
