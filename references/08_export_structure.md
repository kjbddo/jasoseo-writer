# 산출물 정리·내보내기 (표준 구조)

여러 세션·문항에 걸쳐 쌓인 산출물을 이식·재사용(다음 세션, GitHub, 다른 AI 도구) 가능하게 정리한다.

## 표준 폴더·네이밍
```
취업패키지/
├── README.md                     # 목차 + 지원 현황 요약
├── 01_페르소나.md
├── 02_직무역량정리표.md
├── 03_경험개요_14항목.md
├── 04_경험_서술형.md
├── 05_문항주제_매핑.md
├── 06_기업분석_적합서비스.md
├── 07_지원동기.md
├── 08_직무수행노력.md
├── 09_문항답변/                  # 문항별 답변 (강점/협업/성장/입사후포부…)
│   ├── 강점_1000자.md
│   ├── 협업_1000자.md
│   └── 입사후포부_1000자.md
├── 10_평가·개선.md
└── assets/                       # 이력서·포트폴리오·이미지 등 원본
```
- 번호 접두어로 순서를 고정하고, 파일명에 **문항명 + 글자수**를 넣어 검색·재사용을 쉽게 한다.
- claude.ai 프로젝트가 연결돼 있으면 같은 이름으로 프로젝트에도 저장한다.

## README 템플릿
```markdown
# 취업 준비 패키지 — [이름]
- 목표 직무: …
- 지원 현황: [회사/직무] — 상태(작성중/완료/제출)
## 문서 목차
- 01 페르소나 … / 07 지원동기 … / 09 문항답변 …
## 확인·보완 필요(⚠️)
- 정량 성과, 재직 기간, 자격증 취득 시점 등
```

## 내보내기
- 사용자가 "정리/내보내기"를 원하면 위 구조로 파일을 모아 전달하고, README에 **⚠️ 미확정 항목**을
  한데 모아 다음 작업이 바로 이어지게 한다.
