# 평가·개선 (8단계)

두 역할을 순서대로 수행한다.

## 역할 1 · 자기소개서 전문 컨설턴트

구조·방법 기준으로 아래 3부를 준다:
- **✅ 잘된 점** — 구조(두괄식·What/Why/How), Why의 설득력, 협업/역량/태도가 실제 행동으로
  드러나는지, 문장 완성도 등.
- **⚠️ 부족한 점** — 정량 성과 유무, 나의 고유 기여 선명도, 문제 상황의 긴장감, 갈등의 구체성,
  마무리의 차별성, 직무 연관성.
- **🔧 개선 제안(우선순위)** — 가장 임팩트 큰 순으로 실행 가능한 제안.

## 역할 2 · 자기소개서 평가위원 — 채점표 (100점)

| 평가 항목 | 배점 | 점수 | 평가 이유 |
|---|---|---|---|
| 질문 부합도 | 15 | | 질문 의도에 정확히 답했는가 |
| 구조·논리성 (두괄식·What/Why/How) | 15 | | 논리 흐름의 명료함 |
| 구체성·근거 (디테일·정량 성과) | 20 | | 구체 사례·숫자의 유무 |
| 문항 핵심역량 발현 | 20 | | 문항이 보려는 역량(협업/전문성/인성)이 드러났는가 |
| 직무 연관성 | 10 | | 지원 직무와의 연결 |
| 차별성·강점 어필 | 10 | | 흔한 소재를 어떻게 차별화했는가 |
| 문장력·가독성 | 5 | | 문장 완성도 |
| 분량 준수 | 5 | | 요구 글자수 충족 |
| **합계** | **100** | | 등급(A/B+/B…)과 총평 |

- 배점은 문항 유형에 맞게 조정 가능(협업 문항이면 "문항 핵심역량=협업" 가중 등).
- 점수는 후하지 않게, 이유를 구체적으로. 감점 사유가 곧 개선 로드맵이다.

## 개선(리라이트)
사용자가 "반영해 수정"을 원하면 피드백을 직접 반영해 다시 쓴다:
- 감점 컸던 항목(정량성·차별성·나의 고유 기여)을 우선 채운다.
- 지어낸 수치는 본문에 넣되 문서 밖에 `⚠️ 예시 — 실제 값 확인` 을 붙인다.
- 개선 전후 점수 변화(예: 81 → 90 예상)를 알려주고, 글자수를 다시 검증한다.

## 사용자 확인 지점
- 평가 후: 그대로 반영할지 / 실제 수치를 먼저 받고 반영할지 선택.
- 리라이트 후: ⚠️ 예시 수치의 사실 여부 확인.

## 최종 검수 체크리스트 (완성/개선 후 반드시 통과)
문항 답변·지원동기·포트폴리오를 마무리하기 전에 아래를 점검한다:
- [ ] **과장·날조 없음** — 성과 수치·수상·자격증·경험이 사실인가. 추정은 ⚠️로 표시했는가.
- [ ] **문항 부합** — 질문이 요구한 것에 정확히 답했는가(협업 문항에 협업이 드러나는가 등).
- [ ] **글자수** — 요구 글자수(공백 포함 기준) 상한 내 90~100%인가.
- [ ] **소재 중복 없음** — 여러 문항이 같은 프로젝트를 같은 각도로 반복하지 않는가(세트 전체 소재 배분).
- [ ] **용어 일관성** — 기술 용어·회사명·서비스명 표기가 일관적인가.
- [ ] **역할 구분** — 팀 프로젝트에서 '나의 역할'과 '팀의 역할'이 구분되는가.
- [ ] **현재 vs 계획 구분** — 보유 역량과 향후 학습·포부가 섞이지 않고 구분되는가.
- [ ] **가독성** — 만연체·모호한 다짐("열심히 하겠습니다")이 없는가, 두괄식인가.
